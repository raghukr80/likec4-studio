# likec4-studio

LikeC4 Visual Studio — an interactive architecture design studio. Built with React, Vite, TailwindCSS, and ReactFlow.

## Credits

Idea & Design by raghukr80 — https://github.com/raghukr80

## Features

- Light/dark mode (light default)
- Interactive canvas with nodes, connectors, and architecture entities
- Footer with live counts: nodes, connectors, views
- Custom `.ico` icon
